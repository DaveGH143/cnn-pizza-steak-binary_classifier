# Pizza vs Steak Classifier

A deep learning project using Convolutional Neural Networks (CNN) to classify images as pizza or steak.

## Tech Stack
- Python
- TensorFlow / Keras
- Matplotlib

## Models
- CNN model (image classification)
- Basic Neural Network model

## Dataset
Download from:
https://storage.googleapis.com/ztm_tf_course/food_vision/pizza_steak.zip

## How to Run
1. Clone the repo
2. Download dataset
3. Run the notebooks
